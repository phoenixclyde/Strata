## 2 P1 发现（结论方向对、幅度错 / 会带偏下一步）

### P1-1 W793 的 **-3.0%** 是拿 A 臂两个最高样本比出来的；4 个有效样本下只有 **-1.8%**

- **原始台账**（p3 镜像，无表 = base）：
  - `w793_ab_…161311`：A = **34,655**（16:14）、标着 B 的那条 = **34,573**（16:15）。
    那一轮 B/C 臂的 `ensure_up` 用了 `docker start`（对运行中的容器是空操作）⇒ **env 从未改**，所以这两条**都是 base**。
  - `w793b_ab_…161914`：A = **35,419 / 35,537**、B（+表）= **34,356 / 34,486**、C（+SIMT）= 35,210 / 35,489。
  ⇒ base 的有效样本是 **4 个：34,573 / 34,655 / 35,419 / 35,537（中位 35,037，极差 2.8%）**；
    表臂 2 个：**34,356 / 34,486（中位 34,421）**。
- **文档写"B 的两个都比 A 的两个低 ~1,000 ms"** —— 只用了 `w793b` 的两个 A（35,419/35,537），
  把 `w793_ab` 的两个 base 样本（34,573/34,655）**排除在外且未说明理由**。
- 按 4 样本中位：**-1.76%**；若按"最小 A 与最大 B"：**34,573 vs 34,486 = 只差 87 ms（0.25%）**。
- **真正硬的证据是相位**：hc read **3,307 / 3,305 → 2,625 / 2,625（-20.6%）**，而相位自身噪声 0.2%（本文件 §4 台账）。
  680 ms / 35,478 = **-1.9% 端到端**。
- **裁定不变**（采纳表），但收益必须改写：**-1.9%（相位折算）/ -1.8%（4 样本中位）；总量口径不可判。**

### P1-2 W794 的 **-2.7%** 里，有 440 ms 来自一个注意力开关**不可能影响**的相位

### P1-3 W790 的 governor **-2.3%** 是"中位的中位"，三对逐对差的中位是 **-1.2%**

- 连带：W790 §2 的推论"performance 时代基线偏悲观约 2%" → **约 1.2%**。

| P107 rocBLAS 表 | -3.0% | **-1.9%（相位）/ -1.8%（4 样本中位）** | hc read -20.6%，A 自身 2.8% |
| P108 max-ilp | -1.7% | **不可判（方向未否证）** | 跨会话 n=1 |
| P110 attn swizzle | -2.7% | **-1.6%（相位折算）；attn 相位 -8.0%** | A 臂 GU 高 5.8% 与开关无关 |
| P97 governor（旧账，本轮复核） | -2.3% | **-1.2%（逐对中位）** | 三对差值 -1.18/-0.78/-2.32 |

**这不是"结论错了"，是"证据等级被高估"。** 三笔变更的机制都另有独立支撑（表内数值 1.27/2.38、相位置换自逆 + 上游 #1661、hw 无 bf16 点积），所以**不回滚**；但 register 与文档里的百分比必须改成相位口径。

**新规则 P（本项目从此按此判收益）**：
> **先用相位判，再用总量旁证。** 一个开关如果不能在**它声称影响的相位**上留下 ≥ 该相位门槛的变化，就不算生效；
> 总量差只有在"相位差之和 ≈ 总量差"时才可作为幅度依据。凡"总量差 > 相位差之和"的部分，一律记为无关漂移。
