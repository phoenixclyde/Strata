## 1 外证（2026-11-07 上网核；用于设计门，**不代替实测**）

| 来源 | 结论 | 对本门的作用 |
|---|---|---|
| NeurIPS 2026《Length, Not Bit Width: KV-Cache Quantization Moves the Long-Context Retrieval Cliff》(190 runs, 5 深度 × 7 长度 4K–128K, FP16/int8/int4) | 检索失败是**长度悬崖**不是深度衰减（深度边际仅 55–66%）；Qwen FP16 全深度过 96K，量化后只到 32K；**int8 与 int4 失败模式几乎相同**；压缩在该实现里没省到显存，128K prefill 还腰斩 | 门以**长度轴为主**，报「悬崖位置」而不是均值；必须自带全精度/现役基线 |
| vLLM 128K needle（W1042 已引） | FP8 KV 下 128K needle **91% → 13%**，而延迟直方图、短上下文 eval、PPL **全绿** | 短上下文数值/性能全绿**不能**替代长上下文任务门 |
| RULER / NoLiMa / HELMET（compilenrun 综述、Q-Filters、AnchorKV） | 只报 vanilla NIAH 是常见错误；需多深度、干扰项、多跳、非字面匹配；NoLiMa 32K 时 13 个模型里 11 个掉到短上下文基线 50% 以下 | 加深度轴 + 干扰项；**别把「绿热力图」当通过** |

**机理修正（W1044 上网核后改写，推翻 W1043 初稿的乐观推断）**：前三条针对的是 **KV 量化 / 驱逐**（被压缩的是记忆条目本身）。
W1043 初稿据此写「R103 改的是 query 侧点积、KV 一个字节没动 ⇒ 长度悬崖机理上不适用」——**这句话说得太满，已作废**。
本次外证（aiknowledge 量化综述、TrueSight INT8 注意力漂移、SageBwd、technologyonthe 2026-09 生产实践）明确：
**注意力 logits 是量化里最敏感的一层**（softmax 对 0.01 量级的 pre-softmax logit 误差就敏感，指数运算会非线性放大）；
误差在**多层、多 decode 步、随序列长度**上累积；「**8K 上无法区分的配置可能在 64K 退化**，必须按实际长度测」。
R103 动的正是 `QK^T` 点积（`q` 的 int8 打包 + `v_dot4_i32_i8`），属于这一层。
⇒ **误差机制与 KV 量化不同（不是记忆条目丢失），但长度轴照样必须测，G3 的必要性反而更高**。
判据仍用「相对锚的比值随长度是否稳定」而非绝对命中率；**G3 的 2× 阈值是本项目工程约定，没有外部权威依据**，
不得写成「社区标准」。

## 3 取样面（长度 × 深度网格）

- **logits 面（W1044 按取样面可行性收缩，跑之前改定）**：`qq_r103.py` 的 `PROMPT_LENS` **写死 (1000,8000,16000,20000)**，
  且 `cmd_prompt` 用 `max(PROMPT_LENS)` 设 `--max-context`；现成 `set20k.ids.json` 只有 1 个 segment / 20,000 ids。
  ⇒ 本窗口用同源延长的 `set32k.ids.json`（20K ids 周期重复到 32,768，**A/C/D 三臂用同一份**，只做同源自比的相对 KL，不作绝对质量结论），
  长度取 **1K / 8K / 20K / 32K**，三臂 A/C/D 各 4 点；**64K 不做 logits**（gfx906 上 64K prefill 会吃掉整个窗口预算，
  且 yardstick 的 CPU 专家形态与生产不同），**64K 的风险交给下面的 needle 网格**。
  W1042 的 1K/8K/16K/20K 历史 dump 只作对账，**不进 G2 判定**（跨窗口相位会迁移，W797）。
- **任务面**：长度 **16K / 32K / 64K** × 深度 **0% / 50% / 100%** × 臂 **A / C** = 18 次 needle；
  词表用 W1042 的 51 词随机表，code 每臂每点独立 salt，`cached_tokens` 必须为 0（否则该点作废）。
- **生成面**：每个长度的 50% 深度点，两臂贪心生成 64 token，逐 token diff（W807 的解码侧门，底噪为 0）。
- **性能面**：8K / 16K GPU timeline，两臂各 3 次，判 2×CV（当次 run，不跨 run 借方差）。
