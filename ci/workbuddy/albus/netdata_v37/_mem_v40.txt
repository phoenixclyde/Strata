
## 01:34-01:50 看板 v40：整套版式重写（机主：「卡死/更丑了/起码的整齐都没有」）
- 根因：v37→v39 是三层补丁叠加，同名选择器各定义多次（.hostgrid×3 / .tiles×5 / .drow×3 / .kpi×4），
  同特异性靠顺序取胜 => 改一处被后面覆盖，表现为「对齐时好时坏」。**不再打补丁**，<style> 整体重写为
  单层规则（配色 token 保留，版式全换），每个选择器只出现一次。
- 结构：header / 记分板(6 等分) / 显卡 1fr+1fr / 主机(两栏: 左=主值+8 瓦片, 右=存储表+走势)。
  主机原来是三栏，中栏只有 8 瓦片 => 底下空 150px（正是「空多空少」），改两栏 + 瓦片 1fr 行高自撑满。
- 三个踩坑（都写进技能档）：
  1) body 只写 min-height:100vh 时 flex 容器高度恒随内容长，main 的 flex-shrink 永不触发 => 溢出 48px。
     改 height:100vh。
  2) `.card{min-height:min-content}` 会让卡片比 grid 分到的行高更高（行 302 / 卡 340）=> 压到页脚。
     卡片用 min-height:0，下限分别给 #card-ov(72) 与 main(780)。
  3) svg 的 viewBox 会形成 max-content → 行高 → 图高 → viewBox 的正反馈；且 flex 布局下
     `min-height:min-content` 也参与 => 高度自激。用 `flex:1 1 0;height:0;min-height:72px` 断掉。
- 顶栏状态 23 格原来 flex-wrap，换行点由**数值长度**决定（显存 883.40x vs 3084.69x），同一屏两种排法。
  改 2×2 固定栅格（两列等分，四组永远各就各位）。
- 量测：1920x1078 视口 body=980 一屏无滚动；1600/2560 宽均一屏；2560x1440 图表吸收余量。
  字号 7 档(10/11/12/15/22/28/38)，间距 4 的倍数。
- 存储表改「一个表头 + 两行数据」，不再每行重复 读/写/温度/寿命 四个标签。
