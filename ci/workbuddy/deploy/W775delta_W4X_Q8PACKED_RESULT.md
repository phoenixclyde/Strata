## 6 判定：**exact but no gain（不采纳）**

1. **符号一致指向 Q 略慢**（全 10 点 +1.57%、温 8 点 +2.78%），**但量级始终 < 臂内 spread**（A 温 6.6%% / Q 温 18.8%%）=> 按项目纪律（**臂内 spread 才是真判据**）**不判为真实差异**。
2. 上游 `arch_defaults.cpp` 表把 `Q6_PACKED`/`Q8_PACKED` 标在 **gfx1151**，注释值 **decode +2.3%**（S26）=> **收益未迁移**（与 `P40 SH_STREAM` 同形态：上游对本 pack 的收益不外推）。

**必须分流两条车道（否则会被误读成"gfx906 用不了"）：**

| 车道 | 结论 | 证据 |
|---|---|---|
| **可达性**（能不能用） | **能** | (1)本卡二进制字符串表含 `STRATA_Q8_PACKED`/`STRATA_Q6_PACKED`；(2)本车 DT 实证 `native dense: STRATA_Q8_PACKED=1 packed 84 Q8_0 matrices for decode (+1912.5 MiB)` |
| **是否自动开** | **否** | `arch_defaults.cpp`：gfx906 走 `if (!gfx_arch_is_gfx1151(...)) return t;` 时 `t` 仍为空 => **空表**；只有 gfx12 / gfx1151 有表 => **必须显式设 env 才生效** |
| **生产是否在用** | **没用** | LIVE config `env` = 仅 `HSA_OVERRIDE_GFX_VERSION` + `STRATA_PREFILL_CPU_SHARE`（无 PACKED 键）；生产引擎日志近 4,000 行零 `q8_packed\|q6_packed\|packed .* matrices` 命中 |
| **收益** | **未迁移**（+2.3% 未复现） | 本车 20 点实测：全 10 点 +1.57%、温 8 点 +2.78%，但 Q 臂 spread 18.8% > delta |

**旁证（同一模式）**：`arch_defaults.cpp` 里 gfx12（RDNA4）也**只取 gfx1151 表的 prompt 半边**，注释逐字 *"the decode half measured slower on that card, so it stays out"* => 该表的 **decode 半边在第三张卡（gfx906）上同样不兑现**，与我们在 gfx906 的读数方向一致。
3. **代价明确**：+1912.5 MiB VRAM，**零收益** => 纯负。

**=> `P41` 族内 `STRATA_Q8_PACKED` 一项判「exact but no gain」，不采纳**（`P41` 族状态不动，余成员未测）。

## 7 方法论收获

- **每块 r0 是热机项**（A: 27.4 vs 温 22.7；Q: 24.5/27.3 vs 温 23.3）=> 一条 parity 不足以热机。**下一车起每块丢 r0**（本车已按此口径给温 8 点）。
