## 3 两个真实结论（A 级）

**① dot8 能算对，但 int4 激活的精度代价是 int8 的 20 倍**：0.0032 → 0.0648（同一批权重、同一批激活，只换激活位宽）。
这是 W4A4 的真实代价，不是实现误差（host 模拟与 kernel 现在一致到 0.3%）。

**② 原型吞吐对比无效，不能用来判 dot8 的优劣**：

```
dp4a 0.443 ms 0.47 TMAC/s ; dot8 0.594 ms 0.35 TMAC/s ; speedup 0.746x
```

两边都只有生产 MMQ（7.7 TMAC/s）的 1/16 —— 瓶颈是**每 warp 读一整行权重、8 个 warp 重复 8 次**（8× 权重流量），dot 指令不是瓶颈。
在这个形状下 dot8 反而更慢（归约 + `sa4` load 摊在 8 个 token 上），**但这不构成"dot8 没用"的证据**。

### 风险与已知不利证据（必须一起看）

1. **精度**：dot8 的 rel_l2 是 int8 的 20 倍。`W913` 的 KL 分辨率只有 0.0032，若 W4A4 的 KL 落在 0.01 量级，**P4 直接判死**，后面都不用做。
2. **收益上限只有 2.05%**（`W943`，真 kernel 的 dot4 占 30% × VALU 67% × gate/up 20.4%），**压在 2×CV 门（3.2%）之下**。
3. **tile 改造面大**：P2 要动 LDS 布局与 `mmq.cuh` 的尺寸常量，且必须保住 `moe_mmq_tab` 的逐位性。

⇒ 诚实预判：**P4 大概率是终点**。但机主要求实测，所以方案按 P1→P3→P4 做，**P4 一过不了就停**，不做 P5。
