## 4 判定：**无差异（保留默认，无需动作）**

1. **符号在两口径间翻转**：全 10 点 B 快 0.13%、温 8 点 B 慢 0.60% => 无一致方向。
2. **|delta| 远小于臂内 spread**（A 24.0% / B 16.4%，温 8 点）=> 按项目纪律**不判为真实差异**。
3. **与上游自己的限定一致**：relnote 逐字 *"A machine that holds nearly every expert gains nothing"*，且收益场景写明是 *"+10..20% decode on **12-16 GB cards that miss experts**"*。我方 = 32 GB 卡 + `--resident-budget-gib 76` + page cache => **本就"几乎全专家常驻"** => 正落在"gains nothing"那一类。
4. **"在动作"仍成立**（跳过计数确实在涨）---- 但 **动作 != 收益**：被跳过的都是"窗口内每个 token 都排第 7 名或更低"的专家，对单步总耗时贡献本来就小。

**=> 结论：`STRATA_ROUTE_TAIL_SKIP` 保持默认（不设），无动作项。** 这同时把 `P57` 的更正收成一个可执行的量级：**本机开着它，不亏也不赚**。
