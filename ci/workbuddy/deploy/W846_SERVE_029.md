## 1 为什么不能只 `COPY serve`

预检把 0.2.9 的 import 面全扫了一遍，发现三件事：

| 依赖 | 情况 | 处理 |
|---|---|---|
| `strata_control.replica_profile` / `gpu_pick` | **0.2.9 新增文件**，镜像里没有；`serve/replicas.py:204` 会 `from strata_control import replica_profile` | 必须一起替换 `strata_control/` |
| `strata_cli` | 0.2.9 改了 8 个文件（`cli.py`、`launch/*`），serve 顶层 import 它 | 必须一起替换 `strata_cli/` |
| `jsonschema` / `referencing` | 镜像里**没装**；但 `serve/structured.py:76-84` 是**函数内 try/except**，注释就写着 "None when it is not installed" | 不用装，天然降级 |
| `anthropic` | 只在测试里 import；运行时用的是本地 `serve.frontend.anthropic_to_messages` | 不用装 |
| `strata_tokenizer` / `web_i18n` | 在 `tools/` 下，`server.py:4090/8905` 是**函数内延迟导入** | 顺手补进 `/src/tools/` |

所以叠层的实际内容是 **4 处**，不是 1 处：

```
FROM strata-gfx906:0.2.8p2
COPY serve /src/serve
COPY strata_cli /src/strata_cli
COPY strata_control /src/strata_control
COPY tools/strata_tokenizer.py /src/tools/strata_tokenizer.py
COPY tools/web_i18n.py /src/tools/web_i18n.py
```

上下文体积：serve 3.5 M + strata_cli 1.2 M + strata_control 1.4 M + tools 36 K。
构建 **秒级**（基础层全复用），新镜像 6.98 GB（+10 MB）。
