# W891 · R37 结案（DONE_NEG）：专家读已经是 **411 GB/s**，「1.65× 空间」来自过期的 T 和一个算错的槽尺寸

**一句话**：R37 的两块基石都不成立——
① 每专家 **2.99 MB** 是算错的，真值是 **3.135 MB**（`7463 槽 / 21.79 GiB` 直除）；
② 「每窗口 2.60 GB」用的是 **T=1.79** 的旧口径，今天 **T=3.24**、每窗口 **4.75 GB**。
用今天的实测重算：**4.75 GB ÷ 11.58 ms = 411 GB/s = 屋顶 884 的 46.4%**，
对那条 487 GB/s 的**纯读**探针是 **0.84×**（生产比探针低 16%，不是低 65%）。

---

## 1 三个数各自怎么来的

| 量 | R37 / `W863` 用的 | 今天实测 | 差异原因 |
|---|---:|---:|---|
| 每专家字节 | 3.13 MB（正文） / **2.99 MB**（后来的"更正"） | **3.135 MB** | `21.79 × 1024³ ÷ 7463 = 3.135e6`。**2.99 是我自己 11-02 凌晨算错的**（把这个 3.13 "更正"成了 2.99，还写进了 `P250`/`W875`/`W873`/`W879`/`AUDIT20`） |
| 每窗口专家数 | `48 × top10 × 1.79 = 859` | **`48 × 31.59 = 1516`** | T 从 1.79 → 3.24；`VRAM hits` 字段现在**直接打出来了**（`31.59`/层-窗口），不必再乘模型 |
| 每窗口字节 | 2.60 GB | **4.75 GB** | 上面两条的乘积 |
| 专家读时间 | 8.85 ms | **11.58 ms**（GDN 8.68 + QSA 2.90） | 同一窗口，时间随专家数涨，但**涨得比字节慢** ⇒ 带宽反而更高 |
| **带宽** | 295 GB/s | **411 GB/s** | 304（旧口径复算）→ 411 |

复算（可逐位核对）：

```
每槽      = 21.79 GiB / 7463      = 3.135 MB
每窗口专家 = 31.59/层 × 48 层      = 1516
每窗口字节 = 1516 × 3.135 MB      = 4.75 GB
带宽      = 4.75 GB / 11.58 ms    = 411 GB/s   (884 的 46.4%)
对探针     = 411 / 487            = 0.84×
```

## 2 所以「1.65×」是什么

`W863` 的推理是「同样 3.13 MB 粒度，纯读探针能到 487，生产只有 295 ⇒ 空间 1.65×」。
今天生产自己就是 **411**，而 487 是**纯读**（`W862` 的读探针，不含 GEMV 运算）。
⇒ **生产在"读 + 算"的情况下，已经跑到纯读探针的 84%。** 剩下的 16% 不是"浪费"，是两个探针测的东西不同。

**若硬要按 487 追**：4.75 GB 从 11.58 → 9.75 ms，省 **1.83 ms/窗口 = 4.5%**。
但那条路要求"读的时候不算"——不成立。⇒ **R37 结案 DONE_NEG。**

## 3 两次「过期常数」是同一个失效模式

| 轮次 | 条目 | 过期的东西 | 结果 |
|---|---|---|---|
| W889/W890 | R38 | 占用率取的是 **T=2** 的 119 VGPR（生产 T=3.24 ⇒ 140） | 「2.7×」→ 实际杠杆 −19.5% 单条路径，净 +2.8% |
| 本轮 | R37 | 每窗口字节按 **T=1.79** 算（生产 T=3.24） | 「1.65×」→ 实际 **0.84×（已超探针）** |

**共同点**：文档里存的是**派生量**（GB/s、倍数），而派生量的输入（T、槽尺寸）会漂。
⇒ 纪律：**文档只许存"原始读数 + 算法"，派生量每次现算**。已加 `tools/derived_check.py`（见 §5）。

## 5 新增护栏：`tools/derived_check.py`

从**最新一条** `strata decode timing` 行现算下列量，并打印成一段可直接贴进文档的文本：

```
每槽字节、每层-窗口专家数、每窗口专家数、每窗口字节
（若日志里有 GPU stages 行）专家读时间、带宽、占 884 比例、对探针 487 的比值
```

用法：`python tools/derived_check.py`（在 166 上跑，内部 `docker exec` 读日志）。
**规矩**：任何文档要写「GB/s / 倍数 / 占比」之前，先跑它，把输出贴进文档；**不许手算**。
