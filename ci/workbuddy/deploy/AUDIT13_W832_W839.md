## 2 P0

### P0-1　W832 的样本口径写错：36 条 / 36 个 sha，且 3 条不是 512 token

原文（§4.1 后）：「33 条 512-token 生成给出 33 个不同的 sha」。回原始 `w832_tune_results.jsonl`：

```
records 36   distinct sha 36   max share 2.8%
non-512: [('spec_min_p',0.5,446), ('spec_min_p',0.5,318), ('pcie_frac',0.1,420)]
```

⇒ 两个数都错（36/36，不是 33/33），而且**那 3 条只生成了 446/318/420 token 的样本被当成 512-token 计入了中位表**。
这条不影响「生成不可复现」的定性结论（36 个 sha 全不同，反而更强），但**样本量与表内口径**必须改。

### P0-2　W832 的停机条件写在一列、判据在另一列，且该条件永不可能触发

原文：「任一臂的 `ms/win` 与 base 差 < 2%（同实例内噪声预计 ≤1%）即可判无差异」。
按它自己的表复算四臂的 `ms/win` 配对差：**+11.75% / −7.24% / −4.11% / +2.53%**，
**同配置复本基线之间就差 +4.88%** ⇒ 没有任何一臂能落进 2%。

⇒ 该停机条件在这台机器上**结构性失效**。结论（参数轴记 UNRESOLVED、保留现值）本身仍成立——那是按主判据
（`tok/ms`）与 6.0% 噪声底盘判的——但**依据必须换掉**，否则下一个人会以为「已按 <2% 判过」。
