### 表格结构铁律（W1043 补，机主指出「第一张是空表」）

标准一旦立，**字段数与列数都不许缩水**：表头 3 列（`#` / `项` / `值`），分隔行 3 列，
每个数据行也必须是 3 列。GFM 规范（2026-11-07 核）：表头与分隔行列数不等 ⇒ 整段不被识别为表；
数据行少一列 ⇒ **补空单元格**；没有数据行 ⇒ 不生成 `<tbody>`。
W1038–W1042 把 `| 3a | args 明细 | … |` 写成两列 `| 3a args 明细 | … |`，
于是「值」列空、超长第二列把表撑出视口 ⇒ 机主看到空表。
⇒ 没数据写 `—` 不留空、表前后各留空行、`tools/report_lint.py` 的 `T0–T4` 机械拦截。

### 一致性铁律（W913 / W940 两次踩到）

`disk md5 == build md5 == running md5` 必须三方相等，并写进报告。任何一方不等：
- `running ≠ disk` ⇒ 磁盘件已被换过而进程还持旧 inode（重启会静默换版本）；
- `disk ≠ build` ⇒ 磁盘件被改写过（本轮就是 `objcopy` 原地重写）。
